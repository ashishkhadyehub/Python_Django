Edit Category

To edit a Category, we first retrieve the existing record from the database.

Retrieve Record
category = Category.objects.get(Id=id)

The retrieved object is passed to the Model Form using the instance parameter. 

form = CategoryForm(instance=category)
Result: The form displays the existing Category values, allowing the user to modify them.
Understanding instance 
instance = category

The instance parameter tells Django which record should be edited. Without it, Django creates a new record instead of updating the existing one.

Updating Records

After submitting the edited form, Django updates the existing record in the database.

Update View
def editCategory(request,id):

    category = Category.objects.get(Id=id)

    if request.method == "POST":

        form = CategoryForm(
            request.POST,
            instance=category
        )

        if form.is_valid():

            form.save()

            return redirect('categories')

    else:

        form = CategoryForm(
            instance=category
        )

    return render(
        request,
        "editcategory.html",
        {
            "form":form
        }
    )
Result: The selected Category is updated instead of creating a new record.

Delete Category

Django allows us to delete a record using the delete() method.

File Location
demo/views.py
Create Delete View
from django.shortcuts import redirect

from .models import Category

def deleteCategory(request,id):

    category = Category.objects.get(Id=id)

    category.delete()

    return redirect('categories')
Understanding the Code
Code Purpose
Category.objects.get() Retrieve Existing Record
delete() Delete Record
redirect() Return to Category List
Result: The selected Category is permanently removed from the database.
Understanding delete() 
category.delete()

The delete() method permanently removes the selected record from the corresponding database table.

Delete Confirmation

Before deleting a record, it is recommended to ask the user for confirmation.

Delete Link
<a href="/deletecategory/{{ item.Id }}"
   onclick="return confirm('Are you sure you want to delete this category?')"
   class="btn btn-danger">

    Delete

</a>
Result: When the Delete button is clicked, a confirmation dialog is displayed. The record is deleted only if the user clicks OK.
Understanding confirm() 
confirm("Are you sure?")

The JavaScript confirm() function displays a confirmation dialog.

User Action Result
OK Delete the Record
Cancel Stop the Delete Operation

Result: Users can now perform all Category operations from a single page.
Best Practice

Instead of hardcoding URLs, Django provides the {% url %} template tag. 

{% url 'deletecategory' item.Id %}

If the URL pattern changes in the future, only urls.py needs to be updated. The template code remains unchanged.

Note: After creating new Views, we must register their URL patterns in urls.py. Otherwise, Django will return a 404 - Page Not Found error.
Example
path(
    'editcategory/<int:id>',
    views.editCategory,
    name='editcategory'
),

path(
    'deletecategory/<int:id>',
    views.deleteCategory,
    name='deletecategory'
),
