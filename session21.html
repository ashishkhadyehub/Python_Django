Create Category Model

Categories help organize Blog Posts into different sections such as Technology, Sports, Education and Travel.

Each Blog Post will belong to one Category.

Open models.py
blog/models.py
Create Category Model
from django.db import models

class Category(models.Model):

    Id = models.AutoField(primary_key=True)

    Name = models.CharField(max_length=100)

    def __str__(self):

        return self.Name

    class Meta:

        db_table = "BlogCategories"
Explanation
  • Id - Unique identifier for each Category.
  • Name - Stores the Category Name.
  • __str__() - Displays the Category Name in the Django Admin Panel.
  • db_table - property allows us to specify a custom table name in the database.

Create Migration

After creating or modifying a Model, Django must update the database structure.

This is done using Migrations.

Step 1 - Generate Migration
python manage.py makemigrations

Django creates a migration file inside the migrations folder.

Step 2 - Apply Migration
python manage.py migrate

Django creates the blog_category table inside the MySQL database.

Verify Table

Refresh your MySQL database and verify that the table has been created successfully.

Remember

Whenever you create a new Model or modify an existing Model, execute the following commands: 

python manage.py makemigrations

python manage.py migrate

Without these commands, the database will not reflect the changes made in your Model.

Register Model in Admin

By default, newly created Models do not appear in the Django Admin Panel.

We must register the Model before it can be managed through the Admin Panel.

Step 1 - Open admin.py
blog/admin.py
Step 2 - Register Category Model
from django.contrib import admin

from .models import Category

admin.site.register(Category)
Step 3 - Create Admin User
python manage.py createsuperuser

Enter the required details: 

Username

Email Address

Password

Confirm Password
Step 4 - Run Project
python manage.py runserver
Step 5 - Open Admin Panel
http://127.0.0.1:8000/admin/
Result: After logging in, the Categories module will be displayed in the Django Admin Panel.
Why do we register the Model?

Registering a Model tells Django that it should be displayed in the Admin Panel.

Without registration, the Model exists in the database but cannot be managed through the Admin Interface.

Customize Django Admin Panel

Django allows us to customize the Admin Panel to improve data management and branding.

In this section, we will customize the Category listing and change the Admin Panel title.

Step 1 - Customize Category Listing

Open blog/admin.py. 

from django.contrib import admin

from .models import Category


@admin.register(Category)
class CategoryAdmin(admin.ModelAdmin):

    list_display = ['Id', 'Name']
Result: The Category list now displays both the Id and Name columns.
Step 2 - Add Search Box
search_fields = ['Name']
Result: A Search Box is displayed at the top of the Category page.
Step 3 - Add Default Sorting
ordering = ['Name']
Result: Categories are displayed in alphabetical order.
Step 4 - Change Admin Panel Title

Open blog/admin.py. 

from django.contrib import admin

admin.site.site_header = "Blog CMS"

admin.site.site_title = "Blog CMS"

admin.site.index_title = "Welcome to Blog CMS"
Result: The default Django Administration title is replaced with our own Blog CMS branding.
Useful Admin Customizations
  • list_display - Display selected columns.
  • search_fields - Add a Search Box.
  • ordering - Sort records automatically.
